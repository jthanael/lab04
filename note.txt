Python Lab: Hangman Game
In this lab, you will use the Python programming language to build a text-based clone of the classic word game, Hangman. Several variations of this game have been around since at least 1894, including a tabletop game of the same name by Hasbro and the gameshow, Wheel of Fortune.



Hangman is a word-guessing game in which players try to identify a hidden word by guessing one letter at a time. Each incorrect guess adds another part to the gallows and hanging figure, while correctly guessing all the letters wins the game.



Alternative Theme
If you are uncomfortable with the traditional Hangman theme, you may use a different theme for this assignment. The programming requirements remain the same; only the game's visual theme and terminology need to change.



For example, you could create a game where the player is trying to:

Save a character before time runs out
Complete a drawing one piece at a time
Repair a robot
Build a spaceship
Escape from a maze
Reveal a hidden picture


If you choose an alternative theme, please make sure it still provides the same basic gameplay and satisfies all of the programming requirements in this lab.



Whether or not you adapt an alternative theme, I hope you enjoy working on this lab as I had building it! :-)



The level of difficulty of the course is being turned up a notch with this assignment. You will need to think more about how to keep track of program state and how to display program components in the correct place.



Learning Outcomes
Upon completion of this lab, you will know how to:

Use lists and strings to manage game data.
Use loops and conditional statements to control program flow.
Validate and process user input.
Use random selection to make a game more dynamic.
Create and use functions to organize a Python program.
Track and update information during program execution.
Use indexes to work with individual elements of a string or list.
Design a simple text-based game using Python.
